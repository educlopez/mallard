# Newsletter widget

This widget adds the newsletter subscription form of PrestaShop's native **Newsletter subscription** module (ps_emailsubscription) to the front office, so make sure the ps_emailsubscription module is installed & enabled.

Do remember to add the **Error_msg** to the form to make sure error messages show out if anything goes wrong.

A confirmation message will show when a user subscribes to the newsletter. Enabling the **Show the confirmation block** setting to preview the message on the canvas.
