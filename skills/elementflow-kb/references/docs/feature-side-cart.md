# Side cart

### How to create a side cart?

![](https://elementflow.io/img/cms/document/1753.jpg)

Set the **Type** to **Side cart**, a side cart will automatically show out when a product is added to the cart.

### Two ways to build the side cart.

1. Use the **Sidebar Cart** widget, quick & easy, but don't have much control over the layout. [Demo](https://elementflow.io/en/pages/womenswear-38.html).
2. Create the side cart from scratch by using these four widgets combined.
   **Cart product widget**
   **Cart summary widget**
   **Cart button widget**
   **Voucher widget**
   They can be found under the **Shopping cart section** on the left panel of the editor. You can customize every part of it to make it exactly what you like. [Demo](https://elementflow.io/second/en/)
