# CMS page builder

The builder has two widgets:

1. CMS content widget
2. CMS title widget

If you are going to create a cms page template, then the **CMS content widget** has to be added to the page; otherwise, the cms pages will be empty, and you will also not be able to edit the cms pages in the editor.
