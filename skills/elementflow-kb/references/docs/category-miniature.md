# Category miniature

A category miniature is a block that gets used over and over to display a list of categories.

### Category image

It's the category image. There are 3 image uploaders in the back office.

1. Category cover image (Okay)
2. Category thumbnail (Never use it, it should be removed)
3. Menu thumbnails (**Recommended**)

PrestaShop will generate thumbnails for the **cover image** according to the category image types (The default category image type is category_default), so make sure the ratio of your category images is the same as the ratio of the category image types; otherwise, white borders will be added to the category thumbnails.

PrestaShop doesn't generate thumbnails for menu thumbnails. What displays on the frontend is what you upload, for category images, I kinda like this way.
