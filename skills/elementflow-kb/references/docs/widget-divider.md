# Divider widget

The divider widget is one of the most used widgets; here are some examples of what it can do.

### How to create a vertical divider?

1. Set the unit of **Width** to **px**, and set a small value for it.
2. The **Weight** is the height of the vertical divider; set a proper value for it.
3. Set the **Width** of the widget to the same value as the width of the divider in step #1.

Screenshots: [1](https://elementflow.io/img/cms/document/1963.jpg), [2](https://elementflow.io/img/cms/document/1964.jpg), [3](https://elementflow.io/img/cms/document/1966.jpg)

### Another way of creating a vertical divider

Using a container can create a high divider by setting the container to:

1. Layout: Fullwidth
2. Width: 1px
3. A background.
