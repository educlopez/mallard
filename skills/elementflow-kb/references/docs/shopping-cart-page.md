# Shopping cart page

### How to import a shopping cart page?

Importing a premade shopping cart page is a great way to create a customized shopping cart page. Go to BO > Element Flow > Settings > Import and export > to import a shopping cart page.

![](https://elementflow.io/img/cms/document/1930.jpg)

### Create the shopping cart page from scratch.

Go to Element Flow > Theme builder > Native pages > to create a shopping cart template.

Create the shopping cart page by using these four shopping cart widgets combined.

- Cart product widget
- Cart summary widget
- Cart button widget
- Voucher widget

They can be found under the Shopping Cart section on the left panel of the editor.
