# Accordion widget

This widget can be used to create accordions and mobile menus.

### 1. The link field for every item

If an accordion item doesn't have a link, then it will have the **toggle icons** to show its sub content.

If an accordion item has a link, then it's a link. It will have the link icon; its sub-content will never be shown.
