# Blog

The blog feature is a built-in feature of the Element Flow, which means not need to install any blog module. It has the following features:

1. Blog page template
2. Blog miniature with image/video cover.
3. Blog category page template.
4. Related post and related product.

### How the blog feature work?

1. Create a **blog category** first on the **BO > Modules > Element Flow > Content builder > Blog category** page.
2. The second step is to create a blog post template on the **BO > Modules > Element Flow > Theme builder > Templates** page. A blog post template is very much like a product page template; it sets the **layout** of the blog post page. Make sure the **Blog content** widget is added to the template; otherwise, you will not be able to add content to a blog post.
3. Create a blog post, give it a name, and select a category for you.
4. Open the newly created blog post in the editor. Now you can add content to the blog post via the editor.
5. Click on the **Clog** icon on the topbar to manage blog post details.

### What are blog post details

- Summary
- SEO title
- Meta description
- **2 Images:** Main images of a blog post, which will be used in blog miniatures and blog page templates
- **Video url:** Load the video in the Video widget via the Dynamic tag feature.
- Publish: Set a date when the blog post will be published, or leave it empty to publish the post immediately.
- Author
- 3 Custom fields: Add extra info to the blog post.
- Related posts
- Related products
