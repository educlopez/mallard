# Install Element Flow

Use the "Upload a module" button on the "BO > Modules" page to install the `sitebuilder.zip` file.

### FAQ

If installation issues occur, use an FTP client to remove `/var/cache/dev/FrontContainer.php` (if it exists) and `/var/cache/prod/FrontContainer.php` (if it exists).
