# Product gallery widget

### How to have a synchronized thumbs gallery?

Click on a thumbnail, and the main gallery will slide to the larger version of the clicked one. ([demo](https://elementflow.io/?link=https%3A%2F%2Felementflow.io%2Fsecond%2F109-875-solid-rib-yoga-crop-top.html))

1. Add two galleries to a product page.
2. Set one gallery to be the main gallery.
3. Set the other one to be the thumbnail gallery.
