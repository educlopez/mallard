# Setup service

Hire the Element Flow team to set up your site. They set up a site quickly while following best practices.

Pricing: **$100 (base price) + $30 x number of pages = total.**

The base price includes setting up these elements:

- Header
- Mobile header
- Footer
- Sidebars

Pricing stays simple regardless of how many elements are on a page or how much work has already been done on the site.

### Things you need to prepare

- A design for every page.
- Back office and FTP credentials.
- Assets (optional): logo, banners, etc.

To hire the service, contact the Element Flow team from anywhere you can find them.
