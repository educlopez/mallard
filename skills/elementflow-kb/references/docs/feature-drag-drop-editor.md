# Drag & drop editor

Click on the gear icon on the top bar to find page settings, there are import settings for these types of records.

1. **Sidebar**, settings to place a sidebar are on the page setting panel.
2. **Popup**, settings to decide whether or when to show a popup are on the page setting panel.
3. **Blog post**.

Sometimes, you can drop the widget to the place where you like it to be, widgets near the place **jitter**, but that's not a bug, the about-to-be-dropped widget changes the structure, which causes the issue.

Besides drag & drop, another way to add a widget to the canvas is to **double-click** on it, check this YouTube video.

Go to the Advanced tab of a widget, and scroll down to the Responsive section, there are settings to hide the widget.

**Hidden widgets** will disappear from the canvas, they can be found in the Structure panel. If you like you can set the editor to show hidden elements, they will be grayed out, but **not recommended**, because grayed-out elements take up spacing that they shouldn't take.

What does it mean if a widget has a lock icon?

Some widgets rely on certain modules to work. If the **relied-on module** of a widget isn't installed, the widget will get a lock icon to indicate that it isn't usable. Here is a list

- Quick buy widget - Quick buy module (stquickbuy)
- Instagram widget - Instagram feed module (stsbinstagram)
- Contact us widget - Contact form module (contactform)
- Linked products widget - Show products as attributes of another product module (stproductsasattrs)
- Product comment widget and product rating widget - Product comments module (productcomments)
- Loved product widget - Loved product module (stlovedproduct)
- Product filters widget and Active filters widget - Faceted search module (ps_facetedsearch)
- Newsletter widget - Newsletter module (ps_emailsubscription)
