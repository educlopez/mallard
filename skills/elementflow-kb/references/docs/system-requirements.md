# System requirements

| Requirement | Value | Note |
|---|---|---|
| Server RAM (`memory_limit`) | 512M+ | PrestaShop 9 requires 512M; every popular hosting provider provides at least 512M. |
| `post_max_size` | 16MB | You can easily increase the value on your server configuration page. |
| `upload_max_filesize` | 16MB | You can easily increase the value on your server configuration page. |
