# Upgrade Element Flow

There are two ways to upgrade Element Flow:

1. Live Upgrade
2. Using the installation page.

### 1. Live upgrade

The PrestaShop addons team verifies every update, which takes time. With the Live upgrade feature, you can upgrade your Element Flow right after a new update is released.

1. Go to BO > Improve > Element Flow > Settings > License & Update.
2. Click on the "Click new version" button.
3. Once there is a new version, an "Upgrade" button will show up; click on it to upgrade.

Note: Verifying the purchase is required to use the live upgrade feature. Enter your **purchase code**, or **order ID** if you bought the module on addons. The purchase code will work right after the purchase, but the order ID may take around **one day** to work. Contact support if your order ID doesn't work.

### 2. Upgrade by using the installation package

Use the "Upload a module" button on the "BO > Modules" page to upload the new version to your site — it's the same process as install. All your data will be safe; PrestaShop just uploads updated files to your site without doing a reinstallation. Reload the "Modules" page to check if this module has an "Upgrade" button; click it to finish upgrading.

### What's next

1. Go to BO > Modules > Check if the Element Flow module has an "Upgrade" button; click it if present.
2. Go to BO > Improve > Element Flow > Settings, scroll to the bottom, and click "Clear cache" to clear template cache files (important, don't skip this step). See the **Clear cache** section on the [FAQ page](https://elementflow.io/third/posts/faqs-2805.html) for more info.
3. Clear the Smarty cache.
