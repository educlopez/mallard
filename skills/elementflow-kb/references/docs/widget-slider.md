# Slider widget

### How to make the entire slide clickable

Two key points:

1. Set the slide's HTML tag to **a (link)**.
2. **Don't** add any links (Link widget) and buttons (Button widget) inside the slide; otherwise, it will cause HTML syntax errors that break the page. If you do need to add a button, use the Text widget to create a fake button.
